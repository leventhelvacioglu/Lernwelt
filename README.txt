MAVI & TOPRAK LERNWELT

1. Upload index.html, manifest.webmanifest and service-worker.js to any HTTPS web host.
2. Open index.html in Safari on the iPad.
3. Tap Share > Add to Home Screen.

Quick test on a computer:
Open index.html directly in a browser. The learning app works, but offline installation requires HTTPS.

- Separate Mavi and Toprak profiles
- Mathematics: addition/subtraction, multiplication, division and time
- German: articles, word classes, spelling, sentence structure and reading
- Five-question rounds, points and local progress
- Parent overview
- Responsive iPad layout and dark mode
